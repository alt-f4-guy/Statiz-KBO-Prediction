# 일일 운영 진입 흐름 설계

## 목표

저장소 루트에서 `python3 run_pipeline.py` 한 줄로 당일 데이터 갱신부터
실시간 예측 제출까지 실행한다.

## 실행 경계

일일 실행기는 다음 단계만 순서대로 수행한다.

1. 경기 일정 수집
2. 라인업 수집
3. 로스터 수집
4. 선수 기록 수집
5. 원천 데이터 정형화
6. 실시간 예측 및 제출

피처 학습 데이터 재생성, 하이퍼파라미터 튜닝, 모델 재학습, 모델 비교,
대체 모델 백테스트 및 고정 모델 백테스트는 일일 실행에서 제외한다.
따라서 고정된 모델, 학습 데이터 체크섬, 배포 메타데이터와 전향 평가
코호트가 일일 실행으로 변경되지 않는다.

## 환경변수

실행 시작 시 `config/.env`를 자동으로 읽는다. 이미 셸에 설정된 환경변수는
덮어쓰지 않는다. 환경파일이 없거나 필수 인증값이 없으면 네트워크 단계 전에
명확한 오류로 중단한다.

## 오류 처리

각 단계는 기존과 동일하게 별도 파이썬 프로세스로 실행한다. 한 단계라도
종료 코드가 0이 아니면 다음 단계로 진행하지 않는다. 실시간 예측 단계는
당일 모든 경기가 성공 전송 또는 만료 처리되면 종료한다.

## 검증

- 일일 단계 목록에 수집·정형화·예측만 포함되는지 검사한다.
- 환경파일의 세 인증값을 자동으로 읽는지 검사한다.
- 기존 셸 환경변수가 환경파일 값보다 우선하는지 검사한다.
- 전체 단위 테스트와 구문 컴파일을 실행한다.
