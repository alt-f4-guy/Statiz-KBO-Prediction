# 선수 스냅샷 수집 진행률 표시 설계

## 목표

선수별 원천 스냅샷 수집이 진행 중임을 한 줄에서 갱신되는 Rich 진행률 바로 보여 준다.

## 범위

- `scripts.collect.collect_player_stats`는 Rich 진행률 바를 생성한다.
- `collect_player_snapshots`는 선수 한 명의 시즌·일별 요청 처리가 끝날 때 진행 상태를 한 번 알린다.
- 진행률에는 완료 선수 수, 전체 선수 수, 현재 선수 번호, 성공 스냅샷 수, 실패 스냅샷 수, 경과 시간을 표시한다.
- 기존 호출자가 진행 콜백을 전달하지 않으면 현재 수집 동작은 변하지 않는다.

## 설계

`collect_player_snapshots`에 선택적인 `progress_callback` 인자를 추가한다. 콜백은 각 선수 처리 뒤에 완료 수, 현재 선수 번호, 성공 수, 실패 수를 인자로 받는다. 요청 실패로 예외가 발생하면 기존처럼 즉시 중단하므로, 완료된 선수까지만 진행률이 갱신된다.

실행 스크립트는 `rich.progress.Progress`의 단일 작업을 만들고, 콜백에서 해당 작업의 완료 수와 설명 필드를 갱신한다. 선수 목록이 비어 있는 경우에도 진행률 바는 만들지 않고 기존 완료 메시지만 출력한다.

## 검증

- 두 선수 수집에서 콜백이 선수별로 정확히 한 번 호출된다.
- 콜백의 완료 수는 1부터 전체 선수 수까지 증가한다.
- 성공·실패 집계는 해당 선수의 모든 저장 행을 반영한다.
- 기존 콜백 미전달 테스트와 전체 선수 수집 테스트가 통과한다.
